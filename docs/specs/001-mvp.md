# Shipboard MVP

## Goal

Provide a public feedback board where users can submit feature
requests and vote on existing requests.

Product owners can manage suggestions and communicate their status.

## Core flows

### Public user

- View a product's feedback board.
- View existing suggestions.
- Submit a suggestion.
- Vote for a suggestion.

### Product owner

- Sign in.
- View submitted suggestions.
- Change a suggestion status.

## Suggestion statuses

- Under Review
- Planned
- In Progress
- Shipped
- Rejected

## Out of scope

- Comments
- Multiple organizations
- Teams and permissions
- Billing
- Notifications
- AI features
- Integrations
- Analytics
- Custom domains

## MVP completion criteria

A visitor can:

1. Open the public board.
2. Submit a suggestion.
3. Vote for a suggestion.

An authenticated owner can:

1. Open the management interface.
2. See submitted suggestions.
3. Change their status.

The updated status is visible on the public board.
